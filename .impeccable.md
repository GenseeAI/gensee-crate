## Design Context

### Users
Gensee Crate is used by developers and security operators who run coding agents locally and need to understand—and control—what those agents do. The native macOS console should make endpoint coverage, harness protection, policy decisions, alerts, and provenance legible during active development without requiring users to translate raw telemetry or edit hook files by hand.

### Brand Personality
Evidence-first, calm, and technically exact. The product should create confidence that protection is active and understandable, while being candid about missing coverage and degraded states. Copy is concise and operational rather than promotional.

### Aesthetic Direction
A refined native security console that stays visually continuous with the existing Gensee web dashboard: light and dark themes, compact information density, warm-tinted neutrals, restrained red for security emphasis, and the Gensee eye mark. Prefer clear rows, status indicators, and native macOS controls over decorative cards, neon effects, or generic futuristic security imagery.

Historical activity views may use GitHub-like calendar density, adapted to the existing dashboard tokens. Distinct data series may use restrained blue, green, gold, red, and purple accents, but exact values and selection state must remain available without relying on color alone.

### Design Principles
1. Make protection state unmistakable: installed, enabled, unavailable, degraded, and busy must never rely on color alone.
2. Keep consequential controls close to their scope and explain what changes before the user acts.
3. Show unsupported or unavailable capabilities honestly instead of hiding them or implying protection that does not exist.
4. Preserve the dashboard's compact hierarchy and native macOS interaction patterns across light and dark modes.
5. Use the existing Rust CLI and policy engine as the source of truth; the native UI presents and invokes backend behavior rather than duplicating it.
6. Pair color-coded activity with explicit totals, dates, tooltips, and accessible labels.
